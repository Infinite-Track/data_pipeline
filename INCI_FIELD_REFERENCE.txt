이 문서는 INCI API POST /v1/analyze 호출 후 products 컬렉션에 저장되는
필드들의 의미와 가능한 값들을 정리한 레퍼런스입니다.


────────────────────────────────────────────────────────────────────────────────
  1. 제품 전체 안전성 요약
────────────────────────────────────────────────────────────────────────────────

  inci_overall_safety_score  (숫자)
    → 제품 전체의 안전 점수.
    → 범위: 1 ~ 10  (낮을수록 안전, 높을수록 위험 성분 포함)
    → 예시: 3 (상대적으로 안전한 편)

  inci_safety_level  (문자열)
    → overall_safety_score를 기반으로 분류한 안전 등급.
    → 가능한 값:
        "safe"       → 전반적으로 안전한 성분 구성
        "moderate"   → 일부 주의가 필요한 성분 포함
        "high_risk"  → 임신 불가 성분, 고농도 자극 성분 등 포함
    → 주의: 개별 성분이 대부분 "safe"여도, 임신 금지 성분이 하나라도
            있으면 전체 등급이 "high_risk"로 분류될 수 있음

  inci_pregnancy_safe  (불리언)
    → 임산부 사용 안전 여부.
    → 가능한 값:
        true   → 전 성분 임신 중 사용 가능
        false  → 임신 중 피해야 할 성분 1개 이상 포함 (예: Retinyl Palmitate)
        null   → 판단 불가 (성분 정보 부족)

  inci_allergen_flags  (문자열 배열)
    → EU 기준 알레르기 유발 향료 성분 목록.
    → 비어있으면 [] (알레르겐 없음)
    → 예시: ["LINALOOL", "LIMONENE"]


────────────────────────────────────────────────────────────────────────────────
  2. 제품 특성 점수
────────────────────────────────────────────────────────────────────────────────

  inci_clean_beauty_score  (숫자)
    → "클린 뷰티" 기준 충족도. 논란 성분·유해 성분을 얼마나 피했는지.
    → 범위: 0 ~ 100  (높을수록 클린)
    → 예시: 95 → 거의 모든 성분이 클린 뷰티 기준 충족
    → 낮아지는 요인: 파라벤, 설페이트, 포름알데히드 방출제,
                     옥시벤존, 합성 향료 등

  inci_comedogenicity_score  (소수)
    → 모공 막힘(블랙헤드/화이트헤드) 유발 가능성.
    → 범위: 0.0 ~ 5.0  (높을수록 모공 막힘 위험)
    → 기준:
        0   → 모공 막힘 없음
        1~2 → 낮은 위험 (대부분 민감 피부도 무관)
        3   → 중간 위험 (지성/여드름성 피부 주의)
        4~5 → 높은 위험 (여드름성 피부 사용 비추천)
    → 예시: 0.1 → 거의 모공 막힘 없음


────────────────────────────────────────────────────────────────────────────────
  3. 피부 타입별 궁합
────────────────────────────────────────────────────────────────────────────────

  inci_skin_type_compatibility  (객체)
    → 피부 타입별로 이 제품이 얼마나 맞는지 평가.
    → 키: oily(지성), dry(건성), sensitive(민감성),
           combination(복합성), normal(일반), acneProne(여드름성)
    → 각 키의 가능한 값:
        "good"    → 이 피부 타입에 잘 맞음
        "neutral" → 사용 가능하나 특별히 적합하지는 않음
        "poor"    → 이 피부 타입에 맞지 않거나 악화 가능성

    → 예시:
        {
          "oily":        "good",
          "dry":         "good",
          "sensitive":   "neutral",
          "combination": "good",
          "normal":      "good",
          "acneProne":   "good"
        }


────────────────────────────────────────────────────────────────────────────────
  4. 효능 분석
────────────────────────────────────────────────────────────────────────────────

  inci_efficacy_summary  (객체)
    → 성분들을 종합해 어떤 효능이 얼마나 강하게 기대되는지 분석.

    ├─ evidencedIngredientCount  (숫자)
    │   → INCI DB에서 효능 근거가 확인된 성분 수
    │   → 예시: 16 → 전체 32개 성분 중 16개가 효능 근거 있음

    ├─ evidenceScore  (숫자)
    │   → 전체 제품의 효능 근거 강도 종합 점수 (자체 계산값)
    │   → 높을수록 과학적 근거가 풍부한 성분 구성

    └─ topEffects  (객체 배열)  → 상위 효능 목록
        ├─ target  (문자열)  → 효능 카테고리
        │   예시 값:
        │     "anti_hyperpigmentation" → 미백/기미 억제
        │     "hydration"              → 보습
        │     "barrier_repair"         → 피부 장벽 강화
        │     "anti_wrinkle"           → 주름 개선
        │     "antioxidant"            → 항산화
        │     "soothing"               → 진정
        │     "exfoliation"            → 각질 제거
        │
        ├─ compositeStrength  (문자열)  → 해당 효능의 전체 강도
        │   "strong"   → 여러 강한 근거 성분이 함께 작용
        │   "moderate" → 중간 수준의 효능 기대
        │   "weak"     → 효능 성분은 있으나 농도/조합이 약함
        │
        ├─ bestEvidenceLevel  (문자열)  → 가장 높은 과학적 근거 수준
        │   "meta_analysis" → 최고 수준 (다수 임상 연구 종합)
        │   "rct"           → 무작위 대조 임상시험
        │   "in_vitro"      → 세포 실험 수준
        │   "anecdotal"     → 사례 기반 (근거 약함)
        │
        ├─ contributingIngredientCount  (숫자)
        │   → 이 효능에 기여하는 성분 수
        │
        └─ contributingIngredients  (문자열 배열)
            → 이 효능에 기여하는 성분명 (INCI명 대문자)
            → 예시: ["NIACINAMIDE", "TRANEXAMIC ACID", "ARBUTIN"]


────────────────────────────────────────────────────────────────────────────────
  5. 개별 성분 분석 목록
────────────────────────────────────────────────────────────────────────────────

  inci_parsed_ingredients  (객체 배열)
    → 입력한 성분 하나하나를 INCI DB에서 조회한 결과.
    → 제품 성분표 순서대로 정렬됨 (앞쪽 = 고함량).

    각 항목의 필드:

    ├─ inciName  (문자열)
    │   → INCI 표준 성분명 (대문자)

    ├─ found  (불리언)
    │   → INCI DB에서 이 성분을 인식했는지 여부
    │   → false이면 나머지 필드들이 대부분 null
    │   → 인식 못 하는 경우: 독자적 브랜드명, 혼합 성분, 오타 등

    ├─ safetyScore  (숫자)
    │   → 개별 성분의 안전 점수
    │   → 범위: 1 ~ 10  (낮을수록 안전)

    ├─ safetyLevel  (문자열)
    │   → "safe" / "moderate" / "high_risk"

    ├─ isAllergen  (불리언)
    │   → EU 기준 알레르기 유발 성분 여부

    ├─ allergenTypes  (문자열 배열)
    │   → 알레르겐인 경우 유형 목록
    │   → 예시: ["fragrance_allergen"]

    ├─ comedogenicityRating  (숫자 또는 null)
    │   → 개별 성분의 모공 막힘 지수
    │   → 범위: 0 ~ 5  (null이면 데이터 없음)

    ├─ irritancyPotential  (문자열 또는 null)
    │   → 피부 자극 가능성
    │   → 가능한 값: "none" / "low" / "moderate" / "high" / null

    └─ pregnancySafe  (불리언 또는 null)
        → 임신 중 이 성분 사용 안전 여부
        → null이면 데이터 없음


────────────────────────────────────────────────────────────────────────────────
  6. Gemini가 추출하는 추가 필드 (INCI API 외)
────────────────────────────────────────────────────────────────────────────────

  ingredients  (문자열 배열)
    → 브랜드 공식 사이트 / Olive Young / Sephora 등에서 가져온 전성분 목록
    → INCI 표준명 순서대로 나열 (앞 = 고함량)

  description  (문자열)
    → 공식 제품 설명 1~2문장

  skin_concerns  (문자열 배열)
    → 이 제품이 타겟하는 피부 고민
    → 예시: ["Dark spots", "Hyperpigmentation", "Dullness"]

  price_usd  (소수 또는 null)
    → 공식 사이트 기준 달러 가격


────────────────────────────────────────────────────────────────────────────────
  7. 파이프라인 자체 생성 필드
────────────────────────────────────────────────────────────────────────────────

  mention_count       → 리뷰 영상에서 이 제품이 언급된 총 횟수
  ad_mention_count    → 그 중 광고 협찬 리뷰에서 언급된 횟수
  ad_ratio            → 광고 비율 (ad_mention_count / mention_count)
  ad_weighted_score   → 광고 여부를 반영한 신뢰도 점수
                        (일반 리뷰 = 1.0, 광고 리뷰 = 0.1~0.3 가중치)
                        높을수록 일반 리뷰에서 많이 언급된 제품
  video_ids           → 언급된 YouTube 영상 ID 목록


================================================================================
  요약: 한 제품에서 볼 수 있는 전체 필드 목록
================================================================================

  product_name              제품명
  brand                     브랜드
  category                  카테고리 (Serum, Toner, Sunscreen 등)
  description               제품 설명
  price_usd                 가격 (USD)
  skin_concerns             피부 고민 타겟
  ingredients               전성분 목록

  inci_overall_safety_score  전체 안전 점수 (1~10, 낮을수록 안전)
  inci_safety_level          안전 등급 (safe / moderate / high_risk)
  inci_pregnancy_safe        임신 중 안전 여부 (true / false / null)
  inci_allergen_flags        알레르겐 성분 목록 (없으면 [])
  inci_clean_beauty_score    클린 뷰티 점수 (0~100, 높을수록 클린)
  inci_comedogenicity_score  모공 막힘 지수 (0~5, 낮을수록 좋음)
  inci_skin_type_compatibility  피부 타입별 궁합 (good / neutral / poor)
  inci_efficacy_summary      효능 분석 (상위 효능 + 근거 수준)
  inci_parsed_ingredients    성분별 안전성 상세 정보
  inci_coverage              INCI DB 인식률 (found=true 성분 수 / 전체 성분 수, 0.0~1.0)

  mention_count             언급 횟수
  ad_mention_count          광고 리뷰 언급 횟수
  ad_ratio                  광고 비율
  ad_weighted_score         신뢰도 가중 점수
  video_ids                 출처 영상 ID 목록
